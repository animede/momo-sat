# MOMO-SAT 天体観測拡張仕様（OBSERVE モード）

文書番号: MOMO-EXT-002 / Rev A / 2026-07-11
背景: 望遠光学系（f=100mm、画素視野角 5.65 秒角）による恒星の長時間観測可否の検討。
単発長秒露光は姿勢レート安定度（実測 ~18 秒角/s）が支配律速のため、
**短時間露光の連続取得（スタック方式）** を採用し、SILS で成立露光時間を定量化する。
型定義の正: common/types.py（Mode.OBSERVE、shutter_open、st_quat、PIXEL_IFOV_RAD 等）

## 1. 目的（検証課題）

- V1: 慣性方向指向の保持（夜側 = 太陽センサ喪失時の推定劣化込み）が成立すること
- V2: フレーム露光中の像流れ（真値）を記録し、**成立する露光時間**
  （有効フレーム率 ≥80% となる最長露光）を現行センサ構成で定量化すること
- V3: スタートラッカ（ST）追加構成で成立露光時間がどこまで伸びるかを定量化すること
- V4: 露光中の MTQ 停止（ジッタ源排除）と RW 運動量管理の両立（フレーム間脱飽和）
- V5: 観測完了後のスタック済み成果物 1 枚の生成と自律復帰

## 2. FSW 側仕様

- `GroundCommand("OBSERVE", {"ra_deg", "dec_deg", "duration_s", "exposure_s"})` で Mode.OBSERVE へ
- **ガイダンス**: 目標方向 u_eci = (cosδcosα, cosδsinα, sinδ)。R(q_t)@u_eci = [0,0,1]
  （body +Z = カメラを慣性方向へ）。残り自由度は最短回転で可。ω_target = 0
- **フレームシーケンス**（duration_s の観測窓内で繰返し）:
  1. 撮像条件成立を確認 → shutter_open=True を exposure_s 継続（露光）
  2. shutter_open=False を FRAME_GAP_S 継続（読み出し・脱飽和許可窓）
  - 撮像条件: 指向誤差 < 0.5°、対目標レート誤差 < 0.05°/s、ターゲット非掩蔽
    （FSW 判定: 目標方向と地心方向の離角 > 地平線角 + EARTH_LIMB_MARGIN_DEG。
    地平線角 = arccos(R_EARTH/r) を用いた標準式）、RW 各軸 |h| < 0.8×上限
- **露光中の静穏化**: shutter_open 中は mtq_moment = 0（脱飽和禁止）。
  脱飽和はフレームギャップ・条件不成立中のみ
- **推定器**: sensors.st_quat が有効なら TRIAD より高重み（σ=10 秒角相当）で
  姿勢補正・バイアス推定に使用（既存のイノベーション積分則を流用）。
  夜側で sun=None・st_quat=None のときは既存どおりジャイロ伝播
- 観測窓終了（経過 duration_s）で frames_captured 分を機上スタック済み成果物
  **1 枚**として images_stored += 1 し、SUNPOINT へ自律復帰。
  TLM: frames_captured、observe_time（累積露光 [s]）
- 既存の自律遷移（SoC<0.30 → SAFE 等）は OBSERVE 中も有効

## 3. シミュレータ側仕様

- **露光・像流れモデル**: shutter_open のレベル期間を 1 フレームとし、露光中の
  body +Z 軸方向（ECI）の角変位軌跡から像流れを積算:
  smear_rad = ∫|ω_perp|dt（ω_perp = ω から +Z 軸まわり成分を除いた直交成分。
  ロール成分は視野中心の流れに寄与しないため除外、周辺画素への寄与は無視で可）
  → smear_px = smear_rad / PIXEL_IFOV_RAD。フレームイベント
  (t_start, exposure_s, smear_px, occulted, valid=smear_px<1.0 and not occulted)
  を記録（capture_events と同様の仕組み）
- **掩蔽真値**: 目標方向と地心の離角 < 地平線角 + マージンで occulted=True
- **スタートラッカモデル**（ScenarioConfig で有効化、既定無効）:
  ST_UPDATE_HZ 間隔で st_quat = q_true ⊗ δq（δq: 各軸 ST_QUAT_SIGMA_ARCSEC の
  小角ノイズ）。|ω_true| > ST_MAX_RATE_DEG_S では None
- 電力: 露光中 payload 1.5 W（既存の payload_power 負荷と同扱いで可）
- CSV 追加列: shutter_open, frames_total, frames_valid, smear_px_last

## 4. 検証シナリオ S5（sim/scenarios/s5_observe.py）

- 軌道は既存 SSO。**目標 = 軌道面法線方向**（h = r×v の方向、常時非掩蔽）を
  シナリオが軌道初期条件から計算して RA/Dec 化
- タイムライン: t=10 SUNPOINT → t=1500 OBSERVE(duration=1800s, exposure=E)
- **露光時間スイープ**: E ∈ {0.3, 1.0, 3.0, 10.0} s × 構成 {ST なし, ST あり} の
  8 ケースを 1 コマンド（`run_sim.py S5`）で連続実行し、比較表を出力
- 判定（機能 PASS/FAIL）:
  1. V1: 観測窓中の真の指向誤差（+Z vs 目標方向）< 0.5°（全ケース）
  2. V4: 露光中の MTQ モーメント = 0（全露光サンプル）、RW 飽和なし（<0.95）
  3. V5: 観測終了で images_stored+1、SUNPOINT 復帰
  4. フレーム取得が機能（frames_total ≥ 10）。ただし本ゲートは **ST 有り
     または E ≤ 3 s のケースにのみ適用**する。ST 無しの長秒露光では食中の
     ジャイロバイアスドリフトで FSW 自身の推定指向ゲートが閉じ、フレーム数が
     物理的に減る（これは V1 で暴くべき夜側推定劣化の現れであり実装不良では
     ない）ため、対象外ケースは定量報告のみとする（Rev A 改訂）
- 定量出力（判定でなく報告）: ケースごとの有効フレーム率・累積有効露光 [s]、
  「有効率 ≥80% の最長露光時間」を ST なし/ありで比較
- 参考予測: ST なしはレート安定度 ~0.005°/s（18 秒角/s）→ 1px=5.65 秒角 より
  成立露光 ~0.3 s 級。ST ありは推定改善によりレート実誤差が下がり数秒級まで
  伸びる見込み（実際の値はシミュレーションが示すものを報告する）

自律復帰、全 8 ケース。回帰 S1〜S4・全単体テストも PASS）

### 結論

- **有効率 ≥80% の最長露光: ST 無し = なし（0.3 s でも 10%）、ST あり = 0.3 s（89.7%）**
- 現行センサ構成（太陽+磁気 TRIAD）では天体観測は実用不可。食中に推定が
  劣化し、フレーム取得機会そのものが激減する（29 枚 vs ST 594 枚）
- **スタートラッカ追加で成立**: 0.3 s×533 枚 = 観測窓 30 分あたり**有効積算 160 s**。
  実効 30 分露光には約 11 観測窓（≈11 軌道 ≈ 17.5 時間、1 日以内）で到達可能
- 閉ループレート安定度の実測（流れ量から逆算): ST 無 ~32 秒角/s、ST 有 ~11 秒角/s。
  1 s 以上の露光成立には、ジャイロ白色雑音由来の RW 制御チャタリング低減
  （レート推定のローパス化・露光中の低 Kd 化）または焦点面微動補正
  （ASTERIA 方式ピエゾ）が次の改善手段
