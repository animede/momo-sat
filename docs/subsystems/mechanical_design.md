## 1. 構体コンセプト

### 1.1 構体方式トレード

| 項目 | モノコック＋レール一体 | レール＋シアパネル構成（本設計採用） |
|---|---|---|
| 加工性 | 一体削り出しのため大型5軸加工機必須、段取り回数多、コスト高 | レールと側面パネルを分離加工でき、汎用3軸加工機＋簡易治具で対応可能 |
| 剛性 | 一体構造で局所剛性は高いが、内部アクセスのため分割面が必要になり結局ボルト結合が残る | レール4本が主荷重パスとなり、側面パネルはせん断力のみ分担。CDS標準構成として実績多数 |
| 質量 | 肉抜き加工が複雑化しやすく、歩留まりで重量増の傾向 | パネル厚を薄く（1.5〜2mm）でき軽量化しやすい |
| 保守性（MI-2: パネル交換） | 一体構造のため分解範囲が大きくなりがち | ±X/±Y/−Z パネルを個別に脱着でき、太陽電池パネル交換が構体分解なしに可能（MI-2適合） |
| 実績 | 大型衛星・高剛性要求機で採用例あり | 1U〜3U CubeSat の標準構成（ISIS/Pumpkin等の実績） |
| **判定** | 加工コスト・保守性で不利 | **本設計として採用**：4本レール（8.5mm角、6061-T6）が主構造、±X/±Y/−Z側面パネルと+Z光学ベンチがシアパネルとしてレールにねじ結合 |

材料は 6061-T6（MT-1）を全構造部材に採用する。レール接触面は硬質アルマイト処理
（CDS 準拠、耐摩耗・電気導通確保）、その他表面はアロジン処理（導電性化成皮膜）で
ボンディング抵抗 <100 mΩ を確保する。

## 2. 内部レイアウト（Z軸スタック配置）

### 2.1 配置方針

+Z 側（光学ベンチ裏）から −Z 側（S帯パッチ面）に向けて以下のように配置する。

- **+Z 半分**: 光学ベンチ＋鏡筒（全長78mm、フォーカス調整代含む）＋センサ基板（12mm）
- **−Z 半分**: PC/104 スタック（ADCS/通信/OBC/EPS 基板、Z方向に低背ピッチ積層）
  ＋ バッテリブラケット（18650×2、セル軸をZ方向に沿わせた「スパイン型」搭載）
  ＋ RW アセンブリ（ブラケットで−Z面から張り出し搭載）
  ＋ MTQ・GPS・IMU/センサ類・UHFモノポール収納機構・S帯パッチアンテナ

バッテリと RW をスタック直下の薄いスライスに押し込めず、セル長（65mm）を活かして
Z方向に長く配置する「スパイン型」搭載とすることで、重量物の重心をより幾何中心へ
近づけている（§3のCGチューニングの主要手段）。

## 3. 質量特性の計算（ME-4/5/6 検証）

本節の計算は本リポジトリの `.venv/bin/python`（numpy）で実施した。
以下、計算過程を示す。

### 3.1 質量（ME-4）

§2.2 表の質量総和 = **1250 g**。docs/02 の質量バジェット合計と一致。
上位要求（ME-4: ≤1330g）に対し80g（6.4%）の余裕があり、設計マージン目標
≥5%（≥65g）を満たす。

### 3.2 重心位置（CG）計算（ME-5検証）

各機器質量 m_i、位置 (x_i, y_i, z_i) から重心を算出する：

```
CG_x = Σ(m_i × x_i) / Σm_i
CG_y = Σ(m_i × y_i) / Σm_i
CG_z = Σ(m_i × z_i) / Σm_i
```

§2.2 表の全23項目（合計1250g、トリムマス5g含む）を代入して Python で計算した結果：

```
CG_x = −2.69 mm
CG_y = −0.50 mm
CG_z = −17.81 mm
```

**ME-5判定**（幾何中心から各軸 ±20mm 以内、目標 ±10mm）:

| 軸 | CGオフセット | 要求(±20mm) | 目標(±10mm) |
|---|---|---|---|
| X | −2.69 mm | 適合 | 適合 |
| Y | −0.50 mm | 適合 | 適合 |
| Z | −17.81 mm | **適合**（マージン 2.19mm） | **不適合**（目標超過 7.81mm） |

X/Y方向は太陽電池4面・機器のほぼ対称配置により目標±10mm以内に収まる。Z方向は
光学系（+Z側、145g）とPC/104スタック＋バッテリ＋RW（−Z側、重量物集中）の質量
非対称性に起因し、バッテリのスパイン型配置・RWブラケットの張出し配置による
チューニングを行った後も −17.81mm に留まる。これは硬要求（±20mm）には適合するが、
設計目標（±10mm）には未達である。**要上位文書調整または追加トリムマス検討**：
EM段階での実測CGに応じ、+Z光学ベンチ近傍のトリムマス（現状5g、位置z=+50mm）を
増量する、またはバッテリブラケットを可能な範囲でさらに+Z側へ延伸することで
±10mm目標への追い込みを図る。ADCS外乱トルクへの影響は adcs.md §3.3 の
重心-圧力中心オフセット仮定（20mm）の範囲内であり、現状のZオフセット17.81mmは
この仮定を超えないため、AD系の外乱トルク計算（adcs.md）との不整合はない。

### 3.3 慣性テンソル計算（ME-6検証）

各機器を直方体近似し、自重心まわりの慣性（一様直方体公式）に平行軸定理を適用して
幾何中心まわりの慣性テンソルを合成する：

```
Ixx_i = m_i/12×(dy_i² + dz_i²) + m_i×(y_i² + z_i²)
Iyy_i = m_i/12×(dx_i² + dz_i²) + m_i×(x_i² + z_i²)
Izz_i = m_i/12×(dx_i² + dy_i²) + m_i×(x_i² + y_i²)
Ixy_i = −m_i×x_i×y_i,  Ixz_i = −m_i×x_i×z_i,  Iyz_i = −m_i×y_i×z_i
```

全23項目について Python（numpy）で積算した結果（kg m²、幾何中心まわり）：

```
I = [[ 2.3471e-3, −2.432e-4,  1.124e-5],
     [−2.432e-4,  2.3742e-3,  1.034e-5],
     [ 1.124e-5,  1.034e-5,  1.8090e-3]]
```

（トリムマス5g含む全23項目。トリムマスは幾何中心近傍・小質量のため慣性への寄与は
軽微。）主慣性モーメント（固有値、機体主軸まわり）:

```
λ1 = 1.8083e-3, λ2 = 2.1178e-3, λ3 = 2.6042e-3  kg m²
```

**ME-6判定**（`common/types.py` の diag(2.1e-3, 2.1e-3, 1.9e-3) に対し各軸 ±20% 以内）：

| 軸 | 設計値 [kg m²] | 本配置 対角成分 [kg m²] | 差 | 判定 |
|---|---|---|---|---|
| X | 2.100e-3 | 2.3471e-3 | +11.8% | 適合（±20%以内） |
| Y | 2.100e-3 | 2.3742e-3 | +13.1% | 適合（±20%以内） |
| Z | 1.900e-3 | 1.8090e-3 | −4.8% | 適合（±20%以内） |

非対角成分（慣性乗積）の最大値は Ixy = −2.432e-4 kg m² であり、最小主慣性モーメント
（1.8083e-3）に対し約13.4%。主慣性軸は機体軸から数度傾いているが、機体軸自体を
慣性テンソルの対角成分（Ixx, Iyy, Izz）で ME-6 判定する仕様（docs/07 ME-6の記述、
types.py の INERTIA が対角行列であること）に従い、上表の対角成分比較で判定する。
非対角成分（プロダクトオブイナーシャ）はADCS設計（PD制御・B-dot則、adcs.md）の
軸間カップリング外乱として扱われ、adcs.md の外乱トルクバジェット（残留磁気トルク
2.49e-7 N·mが支配的、97%）に対し軽微であることを確認する。具体的な軸間カップリング
トルクの見積り: 非対角成分による角速度誤差カップリングトルクは
τ_couple ≈ |Ixy|×ω² のオーダーで、撮像時姿勢レート上限(AD-3: 0.05°/s=8.7e-4 rad/s)を
代入すると τ_couple ≈ 2.432e-4×(8.7e-4)² ≈ 1.8e-10 N·m であり、RW最大トルク
（1.0e-4 N·m）に対し無視できる水準（0.00018%）である。

**結論: ME-4（質量）・ME-5（CG）・ME-6（慣性テンソル）はいずれも要求を満たす。
ただしME-5の設計目標（±10mm）はZ軸方向で未達であり、EM段階でのトリムマス
最適化を設計フォローアップ事項とする。**

## 4. 構造解析（MS-1/2 検証）

### 4.1 第1次固有振動数概算

放出機構収納状態での最弱部を2箇所について集中質量＋梁ばねモデルで概算する。
6061-T6 のヤング率 E = 68.9 GPa を用いる。

**モデルA: +Z光学ベンチの片持ち支持**

光学ベンチ＋鏡筒＋センサ基板（質量145g）を、+Z面レールから4本のアルミ製
スタンドオフ支柱（外径6mm、有効片持ち長30mm）で支持する構成とする。

```
断面2次モーメント: I = πd⁴/64 = π×(6e-3)⁴/64 = 6.362e-11 m⁴
片持ち梁1本の先端剛性: k = 3EI/L³ = 3×68.9e9×6.362e-11/(30e-3)³ = 4.870e5 N/m
支柱4本合計: k_total = 4×4.870e5 = 1.948e6 N/m
固有振動数: f_n = (1/2π)×√(k_total/m) = (1/2π)×√(1.948e6/0.145) = 583.4 Hz
```

**モデルB: PC/104スタックの曲げ（通しボルト+アルミスペーサ管）**

スタック貫通ボルト（M3×4本）はアルミ製スペーサ管（外径5mm、内径3.4mm、ボルト
クリアランス）を介して各基板を締結する。スタックは−Z面側レール部と光学ベンチ
下部の中間支持で両端固定に近い境界条件とみなし、支持スパンを保守的に56.75mm
（−Z半分の全長）として評価する。

```
スペーサ管の断面2次モーメント: I = π(D⁴−d⁴)/64 = π×((5e-3)⁴−(3.4e-3)⁴)/64 = 2.412e-11 m⁴
両端固定・中央集中荷重の剛性: k = 192EI/L³ = 192×68.9e9×2.412e-11/(56.75e-3)³ = 1.746e6 N/m
スペーサ4本合計: k_total = 4×1.746e6 = 6.983e6 N/m
−Z側搭載品合計質量: m_stack = 775 g（ADCS15+通信40+OBC60+EPS60+電池210+RW150
                                      +MTQ60+IMU40+GPS50+UHF40）
固有振動数: f_n = (1/2π)×√(6.983e6/0.775) = 477.7 Hz
```

**結果**: いずれのモデルも MS-1 要求（≥100Hz）に対し十分なマージン（モデルA:
5.8倍、モデルB: 4.8倍）を持つ。最弱部はモデルB（PC/104スタック曲げ）だが、
477.7Hzは要求の約4.8倍であり、実機でのモーダルサーベイ（MV表）で実測検証する。
本概算は集中質量＋単純梁近似であり、実際にはパネル・レールとの結合剛性も加わる
ため、実機値は本概算より高くなる方向（保守的評価）である。

### 4.2 準静的±15g 強度マージン計算

打上げ質量 M = 1.250 kg（設計目標値）、加速度 a = 15g = 147.10 m/s² として、
総慣性荷重 F = M×a = 1.250×147.10 = 183.87 N を各荷重パスについて評価する。
安全率は降伏1.25・終極2.0（MS-2）を適用する。

**(1) レール圧縮応力・座屈（8.5×8.5mm角、6061-T6）**

```
レール4本が軸方向荷重を均等分担すると仮定: F_per_rail = 183.87/4 = 45.97 N
断面積（中実近似、保守側）: A = 8.5×8.5 = 72.25 mm²
圧縮応力: σ = F/A = 45.97/72.25e-6 = 0.636 MPa

降伏マージン: MS = σy/(1.25×σ) − 1 = 240e6/(1.25×0.636e6) − 1 ≈ +300.8
終極マージン: MS = σu/(2.0×σ) − 1 = 290e6/(2.0×0.636e6) − 1 ≈ +226.9

オイラー座屈（両端固定に近い、有効長係数K=0.65、全長L=113.5mm）:
I_rail = w⁴/12 = (8.5e-3)⁴/12 = 4.109e-9 m⁴
P_cr = π²EI/(KL)² = π²×68.9e9×4.109e-9/(0.65×113.5e-3)² = 54,349 N
座屈マージン: MS = P_cr/(2.0×F_per_rail) − 1 = 54349/(2.0×45.97) − 1 ≈ +590.2
```

**(2) スタック貫通ボルト M3×4本（A2-70ステンレス）**

```
軸方向（Z）荷重を4本均等分担: F_tension = 183.87/4 = 45.97 N/本
M3有効断面積（応力断面積）: As ≈ 5.03 mm²
引張応力: σ = 45.97/5.03e-6 = 9.14 MPa

A2-70 耐力 σy ≈ 450 MPa、引張強さ σu ≈ 700 MPa（一般値）
降伏マージン: MS = 450/(1.25×9.14) − 1 ≈ +38.4
終極マージン: MS = 700/(2.0×9.14) − 1 ≈ +37.3

せん断（横方向、保守的に引張断面積と同一断面で評価）:
τ = 45.97/5.03e-6 = 9.14 MPa
せん断強さ τu ≈ 0.6×σu = 420 MPa
終極マージン: MS = 420/(2.0×9.14) − 1 ≈ +22.0
```

### 4.3 結果一覧

| 部位 | 荷重 | 許容値 | 降伏MS | 終極MS |
|---|---|---|---|---|
| レール圧縮（8.5mm角、4本均等分担） | 45.97 N/本（0.636 MPa） | σy=240MPa/σu=290MPa | +300.8 | +226.9 |
| レール座屈（オイラー、K=0.65） | 45.97 N/本 | P_cr=54,349 N | – | +590.2 |
| 貫通ボルトM3引張（4本、A2-70） | 45.97 N/本（9.14 MPa） | σy=450MPa/σu=700MPa | +38.4 | +37.3 |
| 貫通ボルトM3せん断 | 45.97 N/本（9.14 MPa） | τu=420MPa | – | +22.0 |

1U規模・1.25kg級の衛星では準静的15g荷重は極めて軽微であり、全ての荷重パスで
大幅な正マージンを確保する。支配的な設計制約はMS-2（強度）ではなくMS-1
（剛性・固有振動数）およびMS-3（ランダム振動、GEVS 14.1Grms）であり、
ランダム振動応答の詳細解析（等価準静的加速度換算、Q値考慮）はPFM試験
（MV表: 受入10.0Grms×1分/軸）で実測検証する方針とする。

## 5. アンテナ展開機構（MM-1 詳細）

### 5.1 UHFモノポール諸元の妥当性

```
波長: λ = c/f = 3e8/437e6 = 686.5 mm
λ/4モノポール理論長: L = λ/4 = 171.6 mm
```

437MHz帯のλ/4モノポールは理論上約172mmであり、CubeSat実績（ISIS/AAC Clyde等の
UHFモノポールキット）でも概ね165〜180mm級が採用されている。**本設計では
素子長172mm（λ/4）のテープスプリング型モノポールを採用**する（当初検討していた
「約500mm」は λ/4の約2.9倍でありλ/4モノポールとしては過大、採用しない）。
接地面（1U筐体100mm角）は電気的に波長に対し小さいが、リンクバジェット
（comm.md: 送信アンテナ利得0dBi前提でマージン12.1dB確保）は既に0dBi級モノポール
を前提としており、本素子長で整合する。

### 5.2 収納・展開機構構成

- **収納方式**: テープスプリング（りん青銅またはCu-Be、厚0.15mm×幅8mm）を
  −X面に加工した溝（半径6mm）に巻付け格納。巻付け回転数:
  ```
  周長 = 2π×6mm = 37.7mm
  巻数 = 172mm / 37.7mm ≈ 4.6 turn
  径方向積み上げ厚 = 4.6turn × 0.15mm ≈ 0.68mm
  ```
  溝深さ1.5mm程度で収納でき、ME-3（突起≤6.5mm）に対し十分な余裕がある。

- **保持**: 巻付け終端をナイロン線（径0.4mm、フィッシングライン相当）で係止。
  ナイロン線破断力概算: `F_break = σ_break×A = 50MPa×(π/4×0.4mm²) ≈ 6.3 N`。
  テープスプリングの巻戻りバネ力（保守的に2〜3N相当と想定）に対し十分な保持
  マージンを持つ。

- **溶断（冗長2系統）**: 抵抗溶断方式（ニクロム線抵抗 R≈3Ω、電流 I=2A、
  通電時間 t=5s）。
  ```
  溶断電力: P = I²R = 2²×3 = 12.0 W
  投入エネルギー: E = P×t = 12.0×5 = 60.0 J
  ```
  ナイロン融点（約220℃）に対し十分な熱量を短時間で投入し確実に溶断する。
  系統A・系統Bは独立した抵抗線・独立した駆動FETで二重化し、いずれか一方の
  作動で展開可能とする（MM-1要求の冗長2系統に適合）。

- **展開確認**: アンテナ収納状態で押下されるマイクロスイッチを−X面内部に1個
  配置し、展開完了（テープスプリングが伸展しスイッチが開放）を
  `fault_flags`隣接ビット（telemetry、docs/03 ICD）で取得する。

- **タイマ**: 放出検知（デプロイスイッチ開放、MM-2）から30分以上のタイマ
  経過後に溶断回路を起動する設計とし、CDS要求（放出後30分以上の待機）に適合する。

- **視野遮蔽の確認**: モノポールは−X面に格納・展開し、S帯パッチアンテナ
  （−Z面）・GPSパッチアンテナ（+Y面裏搭載、§2参照）とは異なる面であり、
  収納状態・展開状態ともに両パッチアンテナの視野（各面法線方向±60°程度を
  想定）を機構的に遮らない配置である（MM-1要求に適合）。

### 5.3 収納時突起断面（ME-3検証）

テープスプリング巻付け部の最大径方向積み上げ厚は0.68mm（§5.2）であり、溝深さ
1.5mmに収まるため、レール表面からの正味突起は溝の外側リブ・保持クリップ分を
見込んでも1mm未満である。展開確認マイクロスイッチのアクチュエータボタンも
同様に溝内に収める設計とし、ME-3（突起≤6.5mm）に対し大幅な余裕を持つ。

## 6. 光学系搭載・アラインメント（MP-1/2/3）

### 6.1 光学ベンチへの鏡筒取付とシム調整

鏡筒（CFRP主構造、質量95g）は+Z光学ベンチ板裏面の基準面に3点（または4点）
フランジボルトで固定する。組立時のアラインメント誤差（MP-2: ≤0.1°）は、
フランジ座面に厚み違いのシム（真鍮またはSUS、t=10〜50µm刻み）を挿入して
角度補正する。

ボルト円半径 r=16mm（クリアアパーチャ32mm相当の座面配置）とすると、対向2点間の
シム厚差 Δt と傾き角 θ の関係は：

```
Δt = r × tan(θ)
θ = 0.1° = 1.745e-3 rad のとき:
Δt = 16mm × tan(0.1°) = 16 × 1.745e-3 ≈ 0.0279 mm ≈ 28 µm
```

すなわち、ボルト円上の1点にt≈28µmのシムを追加/削減することで0.1°の角度補正が
可能であり、10µm刻みのシムセットで±0.1°以内のアラインメント調整が実現できる
（MP-2適合）。

### 6.2 熱デフォーカス予算

鏡筒材選定（CFRP主構造＋インバー相当スペーサのハイブリッド、実効熱膨張係数
α_eff≈2e-6/K）および熱変形計算（δL_eff=5.6µm、焦点深度±12.0µmに対しマージン
2.1倍）は payload_optics.md §5 および structure_thermal.md §4 に詳細記載済みで
あり、本書では重複記載を避け参照する。本書の機械設計（§2の鏡筒取付構成、
±Z方向のスタンドオフ支柱による片持ち支持）はこの熱変形評価の前提（鏡筒が
ベンチ基準面に対し軸方向にのみ自由膨張し、径方向の拘束モーメントを生じない
片持ち支持）と整合する。

### 6.3 開口保護カバー・迷光バッフル

- **開口保護カバー（MP-5、RBF扱い）**: +Z開口部にクリーンルーム封止後
  取り付けるスナップオン式キャップ（POM樹脂、アウトガス要求MT-2適合材）。
  RBFピン同様、ディスペンサ収納直前に取り外す運用とし、取り外し忘れ防止の
  赤色フラグ・テザーを付す。
- **迷光バッフル（MP-4）**: 鏡筒内面に段付きバッフルリング（3〜4段）を設け、
  内面は黒色アルマイト処理（反射率5%以下）とする。開口部の視野外光（地球
  リム・太陽近傍散乱光）を多重反射で減衰させる構成とし、鏡筒材（CFRP）表面
  にも同等の低反射処理を施す。

## 7. 電気・アクセスインターフェース（MI-1〜5）

### 7.1 スタック貫通ボルト・パネル取付ねじ

- **スタック貫通ボルト**: M3×4本（MI-1）、§4.2で強度検証済み（終極MS +37.3）。
  全てナイロンパッチまたはねじロック剤（MS-5）で緩み止めを施す。
- **パネル取付ねじ**: ±X/±Y/−Z 側面パネル各面をレールに4本（M2.5、MS-5要求の
  最小サイズ）で固定、合計20本。+Z光学ベンチは6本（M2.5、鏡筒荷重を受けるため
  増し締め）。太陽電池パネル自体はパネル面に対し個別に2本（M2）で固定し、
  構体分解なしに交換可能とする（MI-2）。

### 7.2 アクセスポート（−X面、MI-4）

−X面（UHFモノポール収納溝を避けた領域）に42×20mm程度の開口を設け、以下への
アクセスを収納状態のまま可能にする：

- バッテリ充電コネクタ（EPS基板直結、2ピン）
- デバッグUARTコネクタ（OBC、4ピン）
- RBFピン差込口（MM-3、−X面レール端寄り）
- OBC書換え用SWDコネクタ

開口部にはOリング付き防塵カバー（ねじ2本、M2）を設け、通常運用時は閉止する。

### 7.3 ベント開口面積（MI-5）

内部容積は1U全容積(1000cm³)から構体・基板・機器の実装体積を除いた実効空間として
約0.8Lと見積もる（docs/07 MI-5記載の目安値）。要求は「内部容積1Lに対し≥10mm²」
であり、0.8Lにスケールすると：

```
A_required = 10 mm²/L × 0.8 L = 8.0 mm²
```

−X面アクセスポート防塵カバーに、直径2mmのベント孔を3個設ける：

```
A_vent = 3 × (π/4 × 2mm²) = 3 × 3.14 mm² ≈ 9.42 mm²
マージン = 9.42 / 8.0 ≈ 1.18 倍
```

MI-5要求（急減圧≥3.5kPa/sに対する差圧破損防止の目安開口）に対し適合する。
ベント孔は防塵メッシュ（開口率80%以上のSUSメッシュ）で覆い、打上げ時の異物
混入・音響振動下でのデブリ侵入を防止する（実効開口はメッシュ開口率を考慮しても
9.42×0.8≈7.5mm²とやや目安を下回るため、EM段階で孔径をφ2.2mmへ拡大する
フォローアップを付す）。

### 7.4 展開スイッチ・RBF配置

- **展開スイッチ（MM-2）**: レール端面（+Z側レール2本の端面）に各1個、
  計2個配置。収納中（ディスペンサ内でレール端面が押下される状態）は
  スイッチが機械的にOFFとなり、バッテリを含む全電源を物理的に遮断する
  回路構成とする（CDS準拠）。
- **RBF（MM-3）**: −X面アクセスポート内、レール端に近い位置へRBFピン
  差込口を配置。ピン装着中は展開スイッチと直列に配線され全電源遮断となり、
  ディスペンサ収納作業時（−X面が概ね作業者側を向く搭載シーケンスを想定）に
  アクセス可能である。
