### 2.2 重心位置

Z軸方向（−Z面を原点、+Z面が113.5mm）の機器配置概算位置から重心を算出：

```
CG_z = Σ(m_i × z_i) / Σm_i
```

主要機器の代表Z位置（−Z面基準）: EPS/バッテリ 25mm、通信基板 10〜15mm、
OBC 35mm、ADCS基板 40〜50mm、ペイロード 90mm（光学系全長の中央付近）、
構体・太陽電池・ハーネスは全体均等分布として幾何中心56.75mmに配置。

```
CG_z ≈ 43.4 mm（−Z面基準）
幾何中心（113.5/2） = 56.75 mm
オフセット = 43.4 − 56.75 = −13.3 mm（−Z寄り）
```

バッテリ・EPS等の重量物が−Z側に、光学系（比較的軽量、120g）が+Z側に
配置されるため、重心は幾何中心よりやや−Z側に偏る。この重心オフセットは
ADCS設計（adcs.md §3.3 太陽輻射圧・大気抗力トルク計算）における
圧力中心-重心オフセット仮定（20mm）のオーダーと整合する。

X/Y方向は太陽電池4面（±X, ±Y）・機器の対称配置を基本とし、
重心は幾何中心近傍（±5mm以内）となるよう組立時にトリムマスで調整する
設計方針とする。

## 3. 簡易熱解析（1節点モデル）

### 3.1 前提条件

| パラメータ | 値 | 根拠 |
|---|---|---|
| 太陽定数 S | 1,361 W/m² | 指定値 |
| アルベド | 0.3 | 指定値 |
| 地球赤外放射 I_e | 237 W/m² | 指定値 |
| 太陽光吸収率 α | 0.11 | 太陽電池セル＋構体の面積加重平均（低放射率仕上げ考慮） |
| 赤外放射率 ε | 0.13 | 構体表面（低放射率処理、1U実績オーダー） |
| 放射面積 A_rad | 0.06 m²（6面×0.01m²） | 幾何全表面積 |
| 1面投影面積 A_face | 0.01 m² | 100mm×100mm |

低放射率仕上げ（α, ε とも低め）を採用する理由: 1U規模の衛星は表面積に
対し内部発熱が数W程度と小さいため、放射損失を抑える表面処理
（金蒸着・低放射率コーティング等）が一般的である。α=ε の近似は
太陽電池セル（カバーガラスの吸収率・放射率がほぼ等しい）が
支配的な表面であることに基づく。

### 3.2 定常平衡温度（参考値）

Stefan-Boltzmann放射平衡：

```
T_eq = (Q_in / (ε σ A_rad))^(1/4) − 273.15
```

**ホットケース**（SUNPOINT最大発熱、太陽1面直達＋アルベド/地球IR
副次成分、内部発熱2.25W = RW1.5+OBC0.4+EPS0.1+ADCSセンサ0.1+GPS0.15）:

```
Q_solar = α×S×A_face = 0.11×1,361×0.01 = 1.50 W
Q_albedo = α×albedo×S×A_face×0.3 = 0.11×0.3×1,361×0.01×0.3 = 0.13 W
Q_earthIR = ε×I_e×A_face×0.3 = 0.13×237×0.01×0.3 = 0.09 W
Q_int = 2.25 W
Q_hot = 1.50+0.13+0.09+2.25 = 3.97 W

T_hot = (3.97 / (0.13×5.67e-8×0.06))^0.25 − 273.15 ≈ 34.7 ℃
```

**コールドケース**（食中SAFEモード、地球IRのみ、内部発熱0.9W = EPS0.1
+OBC0.4+MTQ0.2+マージン0.2）、ヒータ1W込みの定常平衡：

```
Q_cold_heated = ε×I_e×A_face×0.3 + 0.9 + 1.0 = 0.09+0.9+1.0 = 1.99 W
T_cold,heated = (1.99 / (0.13×5.67e-8×0.06))^0.25 − 273.15 ≈ −14.1 ℃
```

定常平衡値のみで判定するとコールドケースがTH-1（0℃以上）を満たさない
ように見えるが、食は最大36分の**有限時間**であり、バッテリ・構体の
熱容量により定常平衡には到達しない。§3.3で過渡応答を評価する。

### 3.3 過渡応答評価（食36分間）

熱容量（バッテリ＋周辺構体・基板の代表値）：

```
C_thermal = m_batt×c_batt + m_struct,local×c_struct
          = 0.09kg×1,000 J/kgK + 0.3kg×900 J/kgK
          = 90 + 270 = 360 J/K
```

放射平衡近傍での線形化熱コンダクタンス（T_ref = 日照時平衡温度
+20℃ = 293.15K付近で線形化）：

```
h_rad = 4 ε σ A_rad T_ref³
      = 4×0.13×5.67e-8×0.06×293.15³
      ≈ 0.0446 W/K

τ = C_thermal / h_rad = 360 / 0.0446 ≈ 8,078 s ≈ 134.6 分
```

熱時定数（約135分）は食時間（36分）より十分長いため、食中の温度は
定常平衡値まで低下せず、指数関数的な緩和途中で食が終了する：

```
T(t) = T_eq,cold + (T_0 − T_eq,cold) × exp(−t / τ)
```

日照時の直前平衡温度 T_0 = +20℃（SUNPOINT安定時の代表値）、
食時間 t = 2,160 s として：

**ヒータなし**:
```
T(2,160s) = −55.5 + (20−(−55.5))×exp(−2,160/8,078)
          = −55.5 + 75.5×0.7864
          ≈ +2.3 ℃
```

**ヒータ1W込み**:
```
T(2,160s) = −14.1 + (20−(−14.1))×exp(−2,160/8,078)
          ≈ +12.0 ℃
```

### 3.4 複数軌道連続シミュレーション（定常サイクル確認）

食（36分、上記ヒータあり平衡へ緩和）と日照（58分、+20℃平衡へ緩和）を
交互に5軌道連続適用し、サイクル収束後の食後最低温度を確認：

| 軌道 | 食後温度[℃] | 日照後温度[℃] |
|---|---|---|
| 1 | 12.0 | 14.8 |
| 2 | 8.0 | 12.3 |
| 3 | 6.1 | 11.0 |
| 4 | 5.1 | 10.4 |
| 5 | 4.7 | 10.1 |

サイクルは概ね5軌道で収束し、定常運用における**食直後の最低バッテリ
温度は約+4.7℃**に落ち着く。TH-1要求（バッテリ0〜45℃）を満たし、
ヒータ1W（TH-2）は妥当な容量である。

### 3.5 まとめ

| ケース | 条件 | 結果 |
|---|---|---|
| ホット（定常） | SUNPOINT最大発熱、太陽直達1面 | +34.7℃（≤45℃、適合） |
| コールド（過渡、初回食） | ヒータ1W、食36分、T0=+20℃ | +12.0℃（≥0℃、適合） |
| コールド（複数軌道定常） | ヒータ1W、5軌道連続 | 食後最低 +4.7℃（≥0℃、適合、マージン確認済み） |
| コールド（ヒータなし参考） | 過渡、食36分 | +2.3℃（ヒータなしでも単発食は生存可能だが連続食でマージン減、ヒータ必須と判断） |

## 4. 鏡筒材選定（ST-1、payload_optics.md参照）

光学系の熱デフォーカス評価は payload_optics.md §5 に詳細を記載。
結論として、CFRP主構造＋インバー相当スペーサのハイブリッド構成
（実効熱膨張係数 α_eff ≈ 2e-6/K）を採用し、鏡筒温度変動 ΔT=40℃に
対するデフォーカス量 5.6µm は焦点深度許容量±12.0µmに対しマージン
2.1倍で適合する。
