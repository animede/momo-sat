| ID | 要求 |

| AD-1 | 3 軸姿勢決定精度 0.1°（3σ）以下 |
| AD-2 | 3 軸姿勢制御精度 ±0.5°（3σ）以下（撮像モード） |

| AD-5 | RW 飽和時 MTQ で脱飽和可能 |

慣性テンソル（`common/types.py` `INERTIA` を正とする）:
```
I = diag(2.1e-3, 2.1e-3, 1.9e-3) kg m^2
```
RW: `RW_MAX_TORQUE` = 1.0e-4 N m、`RW_MAX_MOMENTUM` = 1.0e-3 N m s（各軸）
MTQ: `MTQ_MAX_MOMENT` = 0.2 A m^2（各軸）

## 2. 軌道パラメータ

高度 500 km SSO の軌道周期（ケプラー第三法則）：

```
T = 2π√(r³/μ),  r = R_E + h = 6,371,000 + 500,000 = 6,871,000 m
T = 2π√(6.871e6³ / 3.986004418e14) = 5,668 s ≈ 94.5 分
軌道数/日 = 86,400 / 5,668 ≈ 15.24 周/日
```

## 3. 外乱トルクバジェット（500 km SSO）

### 3.1 重力傾斜トルク

```
T_gg = (3μ / 2r³) × |I_z − I_y|_max × sin(2θ)
```
最悪ケース sin(2θ)=1、慣性主軸差の最大値 |I_z−I_y| = |1.9e-3 − 2.1e-3| = 2.0e-4 kg m²：

```
T_gg = (3 × 3.986004418e14) / (2 × 6.871e6³) × 2.0e-4
     = 3.686e-10 N m
```

### 3.2 残留磁気トルク

ICD（docs/03 §4）の環境モデル仕様に基づき残留磁気モーメント m_res = 5.0e-3 A m² を用いる。
地磁気モデル（ダイポール近似、赤道面地表磁場 B_0 = 3.12e-5 T）：

```
B(r) = B_0 × (R_E/r)³ × k_lat
     赤道: B_eq = 3.12e-5 × (6,371,000/6,871,000)³ = 2.487e-5 T
     極（最大, k_lat≈2）: B_max ≈ 4.97e-5 T

T_mag = m_res × B_max = 5.0e-3 × 4.97e-5 = 2.49e-7 N m
```

### 3.3 大気抗力トルク

500 km における大気密度 ρ_atm ≈ 5e-13 kg/m³（太陽活動中位、指数大気近似）：

```
F_aero = 0.5 × ρ_atm × v_rel² × C_d × A
       = 0.5 × 5e-13 × (7,600)² × 2.2 × 0.01
       = 3.18e-7 N

T_aero = F_aero × d_cp-cg
       = 3.18e-7 × 0.02 (重心-圧力中心オフセット仮定 20mm)
       = 6.35e-9 N m
```

### 3.4 太陽輻射圧トルク

```
P_srp = S/c = 1361 / 3e8 = 4.54e-6 N/m²
F_srp = P_srp × A × (1+q) = 4.54e-6 × 0.01 × 1.3 = 5.90e-8 N
T_srp = F_srp × d_cp-cg = 5.90e-8 × 0.02 = 1.18e-9 N m
```

### 3.5 外乱トルク集計

| 外乱源 | トルク [N m] | 支配度 |
|---|---|---|
| 重力傾斜 | 3.69e-10 | 0.1% |
| 残留磁気 | 2.49e-7 | 97% |
| 大気抗力 | 6.35e-9 | 2.5% |
| 太陽輻射圧 | 1.18e-9 | 0.5% |
| **合計** | **2.57e-7** | |

RW 最大トルク（1.0e-4 N m）に対する比：2.57e-7 / 1.0e-4 ≈ **0.26 %** であり、
定常外乱に対して RW トルク容量は十分な余裕を持つ。残留磁気トルクが支配的である。

## 4. RW モーメンタムバジェットと脱飽和

### 4.1 外乱蓄積 vs RW 容量

保守的に外乱トルク合計が半軌道にわたって一方向に働き続けると仮定した
最悪ケースでの角運動量蓄積：

```
H_orbit = T_total × T_period = 2.57e-7 × 5,668 = 1.46e-3 N m s
```

RW 容量（`RW_MAX_MOMENTUM` = 1.0e-3 N m s）に対し H_orbit がこれを上回るため、
**1 軌道以内に脱飽和操作（MTQ オフロード）が必要**という結果になる。
実際には外乱方向は軌道位相・地磁気方向で変動し完全な secular 蓄積ではないが、
保守設計として毎軌道 1 回程度の定期脱飽和運用を計画する（§4.3）。

### 4.2 脱飽和所要時間

MTQ による最大脱飽和トルク（B ≈ 3.5e-5 T 平均、`MTQ_MAX_MOMENT` = 0.2 A m²）：

```
T_mtq_max = m_mtq × B = 0.2 × 3.5e-5 = 7.0e-6 N m
```

RW 飽和角運動量（1.0e-3 N m s）を全量ダンプするのに要する時間：

```
t_desat = H_sat / T_mtq_max = 1.0e-3 / 7.0e-6 = 142.9 s ≈ 2.4 分
```

SUNPOINT モードの定常運用中に MTQ 脱飽和則（クロスプロダクト則、
docs/02 §2.4）を常時有効にすることで、蓄積を抑えながら連続的にオフロードする
運用とし、2.4 分の完全脱飽和時間は 1 軌道（94.5 分）に対して十分小さく、
デューティサイクルの数 % で運用可能。

### 4.3 運用方針

- SUNPOINT / NADIR_IMAGING / TARGET_IMAGING / DOWNLINK の全モードで
  RW 制御と並行して MTQ 脱飽和則を常時有効化（docs/02 記載のとおり）。
- ホイール角運動量が `RW_MAX_MOMENTUM` の 80 %（0.8e-3 N m s）を超えたら
  脱飽和を優先するフラグを立てる設計とする（FDIR 連携は obc_cdh.md 参照）。

## 5. B-dot ゲイン設計（デタンブル則）

デタンブル則: `m = -k_bdot × dB/dt`

### 5.1 MTQ トルク能力とデタンブル時間

初期タンブルレート ω_0 = 10°/s = 0.1745 rad/s から目標 ω_target = 0.5°/s =
0.00873 rad/s まで、MTQ 最大トルクが平均的に実効 50 %（地磁気方向変動による
sin 成分の時間平均）で作用すると仮定：

```
T_mtq_max = m_mtq × B = 0.2 × 3.5e-5 = 7.0e-6 N m
T_eff = 0.5 × T_mtq_max = 3.5e-6 N m
```

除去すべき角運動量（平均慣性 I_avg ≈ 2.03e-3 kg m² を使用）：

```
H_0 = I_avg × ω_0 = 2.03e-3 × 0.1745 = 3.54e-4 N m s
H_target = 2.03e-3 × 0.00873 = 1.77e-5 N m s
ΔH = 3.36e-4 N m s

t_detumble = ΔH / T_eff = 3.36e-4 / 3.5e-6 ≈ 96 s ≈ 1.6 分
```

2 軌道（2 × 5,668 s = 11,336 s）に対し **96 s は約 1.7 % の所要時間**であり、
AD-4 要求に大幅なマージンを持って適合する。

### 5.2 ゲイン選定

B-dot ゲインは、初期タンブルレートで発生する磁場変化率 dB/dt に対して
MTQ 磁気モーメントが飽和値 `MTQ_MAX_MOMENT` に達するように選定する
（バンバン制御に近い最大トルク投入で最速減衰を狙う設計）：

```
dB/dt ≈ ω_0 × B = 0.1745 × 3.5e-5 = 6.11e-6 T/s

k_bdot = m_max / (dB/dt) = 0.2 / 6.11e-6 ≈ 3.27e4  [A m² / (T/s)]
```

タンブルレートが減衰するにつれ dB/dt も小さくなるため、実際の m は
`m_max` 未満に自然に収束し、飽和領域から線形領域へ滑らかに移行する。

## 6. PD 制御ゲイン設計（帯域 ≈ 0.05 Hz）

目標帯域 f_bw = 0.05 Hz、慣性 I = 2.1e-3 kg m²（X/Y 軸、支配的な制御対象軸）、
減衰比 ζ = 0.7（オーバーシュート抑制と応答速度のバランス、標準的設計値）。

```
ω_n = 2π f_bw = 2π × 0.05 = 0.3142 rad/s

Kp = I × ω_n² = 2.1e-3 × 0.3142² = 2.073e-4 N m/rad
Kd = 2 ζ I ω_n = 2 × 0.7 × 2.1e-3 × 0.3142 = 9.236e-4 N m/(rad/s)
```

### 6.1 線形域とトルク飽和チェック

RW 最大トルク（1.0e-4 N m）に対し、Kp のみで飽和しない最大姿勢誤差：

```
θ_sat = T_RWmax / Kp = 1.0e-4 / 2.073e-4 = 0.4825 rad ≈ 27.6°
```

撮像モードの目標誤差（AD-2: ±0.5°）は線形域内に十分収まる：

```
τ(0.5°) = Kp × (0.5° in rad) = 2.073e-4 × 0.008727 = 1.81e-6 N m
飽和比 = 1.81e-6 / 1.0e-4 ≈ 1.8 %
```

レート項についても、デタンブル完了直後の残留レート 0.1°/s 相当での
トルク寄与を確認：

```
τ_rate = Kd × (0.1° /s in rad/s) = 9.236e-4 × 0.001745 = 1.61e-6 N m
```

いずれも RW トルク容量に対し数 % 以内であり、飽和なく線形制御が成立する。
27.6° を超える大角度誤差（モード遷移直後等）では RW が最大トルクで
飽和 slew するのみで発散はしない（PD 則の安定性は保たれる）。

## 7. 姿勢決定設計（TRIAD + ジャイロ伝播）

### 7.1 センサ仕様（ICD: docs/03 §4）

| センサ | ノイズ |
|---|---|
| ジャイロ | σ = 0.01°/s（ARW）、バイアス 0.05°/s |
| 磁気センサ | σ = 100 nT |
| 太陽センサ | σ = 0.1° |

### 7.2 TRIAD 単発精度

磁気センサの角度換算誤差（局所磁場 B ≈ 3.5e-5 T 基準）：

```
σ_mag,angle = deg(σ_B / B) = deg(100e-9 / 3.5e-5) = 0.164°
```

太陽・磁場ベクトルの交差角を保守的に 60° と仮定した TRIAD 合成誤差
（準直交 2 ベクトル観測の標準的近似式）：

```
σ_TRIAD = √(σ_sun² + σ_mag²) / sin(60°)
        = √(0.1² + 0.164²) / 0.866
        = 0.1922 / 0.866
        = 0.222°（1軸, 1サンプル）
```

### 7.3 時間平滑化によるランダム誤差低減

FSW は 10 Hz（0.1 s 周期）でセンサ出力を取得できるため、日照中は移動平均
（簡易 MEKF/相補フィルタ、docs/02 §2.4 記載のとおり簡易実装）による
時間平滑化でランダム成分を統計的に低減する：

```
σ_TRIAD,filtered(N) = σ_TRIAD / √N
```

N = 100 サンプル（10 秒間平均、姿勢保持中の撮像準備時間に対応）で：

```
σ_TRIAD,filtered(100) = 0.222 / √100 = 0.0222°（1σ）
3σ = 0.0665°
```

### 7.4 ジャイロ寄与（フィルタ更新間の伝播誤差）

10 Hz 毎ステップで TRIAD 補正が入る設計のため、ジャイロ伝播誤差は
1 ステップ（0.1 s）分のみ蓄積：

```
バイアス残差（一次推定後、残差を初期値の10%と仮定）: 0.005°/s
ドリフト(0.1s) = 0.005 × 0.1 = 0.0005°
ARW 寄与（0.1s 積分）= 0.01 × √0.1 = 0.00316°
```

### 7.5 AD-1 誤差配分まとめ（RSS 合成）

| 誤差要因 | 1σ [deg] |
|---|---|
| TRIAD（100サンプル平滑後） | 0.0222 |
| ジャイロバイアス残差伝播（0.1s） | 0.0005 |
| ジャイロ ARW（0.1s） | 0.0032 |
| **RSS合計（1σ）** | **0.0225** |
| **3σ** | **0.0675** |

AD-1 要求（0.1° 3σ）に対しマージン約 1.5 倍で適合する。

### 7.6 食中の姿勢決定

食中（最大 36 分）は太陽センサが使用不可（`sun` が None）となるため、
ジャイロのみの慣性伝播に切り替わる。バイアス残差 0.005°/s とすると：

```
ドリフト(36分) = 0.005 × 2,160 s = 10.8°
```

この誤差は撮像を伴わない SUNPOINT / SAFE モードでの姿勢保持中に許容される
（AD-1 は主に撮像モード時の要求と解釈）。日照復帰後、TRIAD 補正が
再び有効化されることで数十秒〜1 分程度（N=100〜600 サンプル平滑）で
AD-1 精度に復帰する。撮像運用（NADIR_IMAGING/TARGET_IMAGING）は
日照区間に計画することを運用コンセプト（concept_of_operations.md）で規定する。
