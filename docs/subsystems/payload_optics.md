## 2. 光学構成トレード（折返しカセグレン vs テレフォト屈折）

| 項目 | 折返しカセグレン（主鏡+副鏡） | テレフォト屈折（本設計採用） |
|---|---|---|
| 光路長 | 主鏡焦点距離の畳込みで短縮可（f/D 大でも全長を抑制） | テレフォト比 T = L/f で全長を焦点距離以下に圧縮 |
| 口径 30mm では | 副鏡径・遮蔽・迷光バッフルの製作誤差影響が口径比で相対的に増大、1U 幅 100mm 筐体内での鏡支持構体が過大 | 口径が小さいためレンズ群のみで完結、遮蔽なし、開口効率100% |
| 収差補正 | RC 系は球面収差・コマ収差ゼロだが像面湾曲補正に追加レンズが必要 | 望遠部＋補正群（正レンズ+負レンズの望遠系）で色収差・像面湾曲を同時補正可能 |
| 組立公差 | 主鏡-副鏡間隔誤差がデフォーカスに直結、口径 30mm 級では鏡面精度・支持機構の相対誤差が大きくなる | レンズ間隔は鏡筒機械加工精度で管理でき、量産・組立が容易 |
| コスト/実績 | 反射光学系は小口径になるほど製作コストが不利 | 30mm 級テレフォトレンズは民生カメラレンズと同カテゴリで実績多数 |
| **判定** | 口径 50mm 級では有利だったが、30mm 級では遮蔽損失・製作誤差の相対的増大で不利 | **1U 収容性・製作性・コストで優位、本設計として採用** |

### 2.1 テレフォト比の成立性

テレフォト比 T は光学全長 L と焦点距離 f の比で定義される。

```
T = L / f ≤ 0.7 （要求 PL-1）
L ≤ 0.7 × f = 0.7 × 100 mm = 70 mm
```

正負合成の望遠系（前群正レンズ＋後群負レンズ）で T ≈ 0.6〜0.7 は一般的な民生テレフォトレンズで実績のある値であり、L = 70 mm を採用する。センサ基板・フィルタ・機械マージンを含めた光路長：

```
L_total = L_optics + L_sensor_stack + L_margin
        = 70 mm + 12 mm（IMX547 パッケージ＋基板） + 8 mm（フォーカス調整・遮光）
        = 90 mm
```

1U 軸方向内寸 ≈ 90 mm（PL-1）にちょうど収まる。マージンはフォーカス調整機構（後述§5）で吸収する。

## 3. 回折限界分解能

レイリー基準の角分解能：

```
θ_R = 1.22 × λ / D
```

λ = 550 nm（可視光帯域中心）、D = 30 mm を代入：

```
θ_R = 1.22 × 550e-9 / 0.030 = 2.237e-5 rad = 22.4 µrad
```

高度 500 km での回折限界地上分解能：

```
GSD_diff = θ_R × h = 22.4e-6 × 500,000 = 11.2 m
```

## 4. GSD 計算とナイキスト評価

画素サイズ・焦点距離からの幾何学的 GSD：

```
GSD_pixel = h × p / f = 500,000 × 2.74e-6 / 0.100 = 13.7 m
```

MR-1（GSD ≤ 15 m）を満たす。

エアリーディスク径とナイキストサンプリングの整合：

```
d_Airy = 2.44 × λ × F = 2.44 × 550e-9 × 3.3 = 4.43 µm
```

画素ピッチ 2.74 µm に対し d_Airy/p ≈ 1.6（1.5〜2.0 が望ましいレンジ）であり、
エアリーディスクが画素の約 1.6 倍でナイキスト条件（サンプリング周波数がカットオフ周波数の
2 倍以上）をほぼ満たす。回折限界 MTF のカットオフ周波数：

```
f_c = 1 / (λ F) = 1 / (550e-9 × 3.3) = 551 cycles/mm
```

画素サンプリング周波数（ナイキスト）は 1/(2p) = 1/(2×2.74e-6) = 182 cycles/mm であり、
f_c (551) > f_Nyquist (182) のため回折限界より画素側が分解能を制限する
（= GSD_pixel 13.7 m が実効分解能、GSD_diff 11.2 m は理論上限）。
すなわちシステムは「わずかに画素制限（pixel-limited）」であり、エイリアシングの懸念は小さい。

## 5. 熱デフォーカス許容量と鏡筒材選定

焦点深度（Depth of Focus, DoF）は：

```
DoF = ± 2 λ F²
    = ± 2 × 550e-9 × 3.3²
    = ± 2 × 550e-9 × 10.89
    = ± 1.198e-5 m = ± 12.0 µm
```

軌道上の温度変動（TH-1: −20〜+60 ℃、鏡筒設計目標 ΔT ≈ 40 ℃）に対し、
鏡筒の熱膨張によるレンズ間隔変化 δL がこの ±12 µm 以内に収まる必要がある。

```
δL = α × L × ΔT
```

**アルミ鏡筒（α = 23e-6 /K）の場合：**
```
δL = 23e-6 × 0.070 × 40 = 6.4e-5 m = 64 µm  → DoF 超過（NG）
```

**インバー相当鏡筒（Fe-Ni36%、α = 1.2e-6 /K）の場合：**
```
δL = 1.2e-6 × 0.070 × 40 = 3.4e-6 m = 3.4 µm  → DoF 内（余裕約 3.5 倍）
```

**CFRP（炭素繊維強化樹脂、準等方積層、α ≈ 2〜3e-6 /K）の場合：**
```
δL = 2.5e-6 × 0.070 × 40 = 7.0e-6 m = 7.0 µm  → DoF 内（余裕約 1.7 倍）
```

質量制約（1U 全体 1200 g、ペイロード配分 120 g）から、密度の大きいインバー
（8.1 g/cm³）は鏡筒全体には使えないため、**CFRP 鏡筒＋インバー製レンズ
セル（要焦点維持部のみ）のハイブリッド構成**を採用する。これにより：

- 鏡筒主構造：CFRP（軽量、比剛性高、α 抑制）
- 光学素子間隔を決める鏡胴内筒：インバー相当スペーサ（局所使用、質量増小）

を組み合わせ、実効熱膨張係数を α_eff ≈ 2e-6 /K 程度に抑える設計とする。

```
δL_eff = 2e-6 × 0.070 × 40 = 5.6e-6 m = 5.6 µm  → DoF (12.0 µm) に対しマージン 2.1 倍
```

ST-1（デフォーカス許容量の抑制）を満たす。

## 6. 露光時間・像流れ

対地速度 v_g = 7.6 km/s（500 km SSO、周回速度と地球自転の合成、docs/01 記載値）に対する像流れ：

```
blur = v_g × t_exp
```

PL-3 上限の 1 ms では：
```
blur(1ms) = 7,600 × 0.001 = 7.6 m = 0.55 × GSD（13.7 m）
```

これは PL-3 の許容値（≤ 0.6 GSD 相当のオーダー）にほぼ一致するが、SNR 検討（§7）の
結果を踏まえ、本設計では**運用露光時間 t_exp = 0.5 ms** を採用する：

```
blur(0.5ms) = 7,600 × 0.0005 = 3.8 m = 0.28 × GSD
```

像流れを 1 画素未満（0.28 GSD）に抑え、AD-3（撮像中レート 0.05°/s 以下）との
組合せ誤差も含めた総合ボケを画素サイズ以下に維持する。

## 7. SNR 概算

### 7.1 地表放射輝度

太陽光を仮定した地表反射輝度（ランバート反射面近似）：

```
L = ρ × E_sun_band / π
```

- ρ = 0.2（植生・土壌・都市域の平均反射率、可視域代表値）
- E_sun_band：550 nm 中心、帯域幅 100 nm での太陽分光放射照度
  （AM0 太陽スペクトル ≈ 1.8 W/m²/nm @ 550 nm）
  ```
  E_sun_band = 1.8 W/m²/nm × 100 nm = 180 W/m²
  ```

```
L = 0.2 × 180 / π = 11.46 W/m²/sr
```

### 7.2 焦点面照度

拡張ランバート光源に対する像面照度の標準式（F 値ベース、透過率込み）：

```
E_image = L × π / (4F²) × τ_optics
```

τ_optics = 0.85（レンズ群 4〜5 枚、反射防止コート、遮蔽なしのため透過率を
折返し系より高く設定）、F = 3.3：

```
E_image = 11.46 × π / (4 × 3.3²) × 0.85 = 0.702 W/m²
```

### 7.3 画素あたり信号電子数

画素面積 = (2.74 µm)² = 7.51e-12 m²、光子エネルギー E_ph = hc/λ = 3.61e-19 J（λ=550nm）、
量子効率 QE = 0.6：

```
P_pixel = E_image × A_pixel = 0.702 × 7.51e-12 = 5.27e-12 W
```

t_exp = 0.5 ms における光子数・信号電子数：

```
n_photon = P_pixel × t_exp / E_ph = 5.27e-12 × 5e-4 / 3.61e-19 ≈ 7,300 photons
signal_e = n_photon × QE ≈ 4,380 e-
```

IMX547 相当の飽和電子数（フルウェル）を約 8,000 e- と仮定すると、
フルウェル使用率 ≈ 55 %（余裕あり、白飛び回避）。

### 7.4 SNR

読み出しノイズ σ_read = 6 e-（典型的な小型 GS-CMOS）、ショットノイズ = √signal_e：

```
σ_shot = √4,380 ≈ 66.2 e-
σ_total = √(σ_shot² + σ_read²) = √(66.2² + 6²) ≈ 66.5 e-
SNR = signal_e / σ_total = 4,380 / 66.5 ≈ 66
```

SNR ≈ 66（≈ 36 dB）は中分解能地表撮像として十分な画質（一般的な要求下限
SNR 20〜40 を上回る）であり、JPEG 圧縮後も判読性を確保できる。

## 8. 露光時間の設計判断まとめ

| 項目 | t_exp = 1.0 ms（PL-3上限） | t_exp = 0.5 ms（採用） |
|---|---|---|
| 像流れ | 7.6 m（0.55 GSD） | 3.8 m（0.28 GSD） |
| フルウェル使用率 | 109 %（飽和） | 55 %（適正） |
| SNR | ― （飽和のため無効） | 66 |

飽和回避と像流れ抑制の両立から t_exp = 0.5 ms を運用値として採用する
（PL-3 の 1 ms 以下要求に対し 2 倍のマージン）。
