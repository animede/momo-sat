## 1. 物理原理の整理

### 1.1 一様磁場中の磁気双極子に働く力とトルク

コイル（電流ループ）を磁気モーメント m のベクトルとして扱うと、外部磁場 B 中での
ローレンツ力の総和（微小電流要素 I dl に働く力 dF = I dl × B を閉曲線に沿って積分）
から、一般に以下が成り立つ（Griffiths, *Introduction to Electrodynamics* 等、標準的な
電磁気学の教科書結果）。

**トルク:** τ = m × B　　**並進力（一般形）:** F = ∇(m · B)

ここで m は電流分布に固有（電流と面積で決まる）であり、場に依存しない。

**一様磁場の場合**（B が空間的に一定）: 成分表示で F_i = ∂(m_j B_j)/∂x_i =
m_j ∂B_j/∂x_i となるが、B_j が全空間で定数（∂B_j/∂x_i = 0）であれば F_i = 0 が
全成分について成立する。一方 τ = m×B は B の空間微分を必要とせず、大きさ・向きの
みで決まる。したがって**一様磁場中では正味の並進力はゼロで、生じるのはトルクのみ**
という命題が数学的に厳密に成り立つ。

→ この意味で、過去文献の「生じるのは力のモーメント（トルク）」という記述は
**一様磁場近似の下では文字通り正しい**。地球磁場は CubeSat のスケール（10cm）
に対しては局所的にほぼ一様とみなせるため、この近似は物理的に妥当である。

### 1.2 非一様場（実際の地球磁場）での並進力

実際の地球磁場は高度・緯度で変化する非一様場であるため、勾配項はゼロではない。
地球磁場を軸対称ダイポール近似すると（sim/environment.py の実装と整合）:

```
B(r, θ) = (B0 R_E³ / r³) [2 cosθ  r̂ + sinθ  θ̂]      (磁気双極子座標、θ: 磁気余緯度)
```

大きさのオーダーは:
```
|B(r)| ~ B0 (R_E/r)³
```

**動径方向勾配**（オーダー評価、r による微分の主要項）:
```
∂|B|/∂r ~ -3 |B| / r
∴ |∇B| ~ 3|B|/r
```

高度 500 km（r = 6.871×10⁶ m）での数値評価:

```python
B_local = B0 * (R_E/r)**3
     = 3.12e-5 * (6371.0/6871.0)**3
     = 3.12e-5 * 0.7972
     = 2.487e-5 T

|∇B| ~ 3 * B_local / r
     = 3 * 2.487e-5 / 6.871e6
     = 1.086e-11 T/m
```

**この非一様性が MOMO-SAT のスケール（0.1 m）に対して極めて緩やかであること**にも
注意する。10cm 移動しても B の変化量は 1.086e-11 × 0.1 ≈ 1.1e-12 T、すなわち
局所磁場 2.487e-5 T に対して相対変化 4×10⁻⁸ 程度に過ぎない。したがって
「一様磁場近似が良い近似である」こと自体が定量的に裏付けられる。

### 1.3 MOMO-SAT の最大並進力 F_max

並進力の上限は、磁気モーメントを勾配方向に完全に整列させた理想ケースとして

```
F_max = m_max · |∇B|
      = 0.2 [A m²] × 1.086e-11 [T/m]
      = 2.172e-12 N
      ≈ 2.17 pN
```

比較として、同じ磁場中でのトルク最大値は

```
τ_max = m_max · B_local = 0.2 × 2.487e-5 = 4.974e-6 N·m ≈ 5 μN·m
```

トルクは μN·m オーダーで実用的な大きさ（RW 脱飽和や B-dot デタンブルに十分）だが、
並進力は pN オーダーであり、**6桁以上小さい**（無次元的には F_max × r / τ_max ~
|∇B|·r/B ~ 3 という比例関係にすぎないが、力と長さの次元が違うため直接比較はできない。
実用上重要なのは以下の §2 の運動への換算である）。

## 2. 軌道力学的な評価

### 2.1 理想ケースの da/dt（ガウスの惑星方程式）

円軌道に対するガウスの摂動方程式（進行方向＝接線方向の加速度 a_t のみを仮定）:

```
da/dt = 2 a_t / n
```

ここで n は平均運動：
```
n = sqrt(μ / r³) = sqrt(3.986004418e14 / (6.871e6)³) = 1.1085e-3 rad/s
```
（軌道周期 T = 2π/n = 5668 s ≈ 94.47 分、円軌道速度 v = sqrt(μ/r) = 7616.6 m/s。
問題文の 7.6 km/s と整合。）

MTQ による進行方向加速度の理想上限:
```
a_t = F_max / m_sat = 2.172e-12 / 1.25 = 1.738e-12 m/s²
```

これを常時・最適方向（進行方向）に維持できたと仮定した理想上限:
```
da/dt = 2 × 1.738e-12 / 1.1085e-3 = 3.135e-9 m/s
```

積算すると:

| 期間 | Δa（理想上限） |
|---|---|
| 1 軌道（5668 s） | 1.78×10⁻⁵ m（約 18 μm） |
| 1 日 | 2.71×10⁻⁴ m（約 0.27 mm） |
| 1 年 | 9.89×10⁻² m（約 9.9 cm） |

すなわち、**理想的な最良条件（磁気モーメントを常に勾配ベクトルに完全整列させ
続けられると仮定）でも、1 年間で高度を 10 cm も上げられない**。

### 2.2 軌道 1 周での平均化効率（上界評価）

実際にはダイポール磁場の向きは軌道上の位置（磁気余緯度 θ）により回転し、MTQ の
方向を瞬時に切り替えても得られる並進力の向き・大きさは軌道位相に依存する。
θ を 0〜2π まで走査し、各位相で |m|=m_max を局所勾配方向に完全整列できたと
仮定する（アクチュエータ応答遅れ・電力制約を無視した上界評価）:

```python
B(θ) 大きさ: B0(R_E/r)^3 * sqrt(1+3cos^2θ)
F_max(θ) = m_max * 3*B(θ)/r
```

数値走査の結果:
- F_max(θ) の範囲: 2.17×10⁻¹² N 〜 4.34×10⁻¹² N
- 軌道平均 〈F_max〉 = 3.35×10⁻¹² N
- 平均化係数 〈F_max〉/F_max,peak ≈ 0.77

つまり軌道全体を通じた幾何学的な平均化ロスは高々 O(1)（係数 1〜2 程度の範囲）
であり、**桁を変えるような効果ではない**。§2.1 の pN オーダーの結論は、この平均化
を考慮しても変わらない。

### 2.3 大気抵抗との比較

高度 500 km での大気抵抗力（指定パラメータ: ρ ≈ 1×10⁻¹³ kg/m³, C_d = 2.2,
A = 0.01 m², v = 7.6×10³ m/s）:

```
F_drag = (1/2) ρ C_d A v²
       = 0.5 × 1e-13 × 2.2 × 0.01 × (7.6e3)²
       ... (v = 7616.6 m/s を厳密値として使用)
       = 6.354e-8 N
```

対応する減速加速度と da/dt（大きさ、符号は負＝軌道低下方向）:
```
a_drag = F_drag / m_sat = 6.354e-8 / 1.25 = 5.083e-8 m/s²
da/dt|_drag = 2 a_drag / n = 9.171e-5 m/s
  → 1 日あたり: 7.92 m/day
  → 1 年あたり: 2894 m/year（約 2.9 km/year）
```

**MTQ による理想上限（F_max = 2.17 pN）と大気抵抗（F_drag = 63.5 nN）の比較:**

```
F_drag / F_max = 6.354e-8 / 2.172e-12 = 2.925×10⁴
```

対数で表すと **約 4.5 桁（10⁴〜10⁵ 倍）**、大気抵抗による減衰力が MTQ の
理想上限並進力を上回る。加速度・da/dt で見ても同じ比（次元が同じ質量・角速度
で規格化されるため）で 4.5 桁の差になる。

すなわち、MOMO-SAT が MTQ で生み出せる最大限の並進力を四六時中、理想方位に
出し続けたとしても、高度 500 km の大気抵抗による軌道低下を**打ち消すことすら
できず**、実際の高度変化は大気抵抗が支配的（年間 3 km 弱の自然減衰に対し、
MTQ 補正は年間 10 cm 未満）である。

### 2.4 大気抵抗を相殺するために必要な磁気モーメント m_req

大気抵抗を相殺する条件 F_MTQ ≥ F_drag より:
```
m_req = F_drag / |∇B| = 6.354e-8 / 1.086e-11 = 5.851×10³ A·m² （約 5850 A·m²）
```

MOMO-SAT の MTQ 上限（0.2 A·m²）に対して:
```
m_req / m_max = 5851 / 0.2 = 2.925×10⁴ 倍
```

**約 3 万倍の磁気モーメントが必要**（§2.3 の比と当然一致する。F ∝ m なので当然）。

#### コイル質量・消費電力の概算

磁気モーメント m = N I A（N: 巻数、I: 電流、A: ループ面積）。1U 内に収まる
ループ面積として A = 0.008 m²（10cm 角パネルにマージンを見た値）を仮定すると、
必要な起磁力（アンペア・ターン）は:

```
N I = m_req / A = 5851 / 0.008 = 7.31×10⁵ A·turns
```

銅線抵抗率 ρ_Cu = 1.68×10⁻⁸ Ω·m、平均 1 巻の長さ L_turn ≈ 4√A ≈ 0.358 m として、
巻線径 0.5〜2.0 mm・電流 0.1〜1.0 A の組み合わせで銅重量と消費電力を試算した
（電力は P = I² R_total、銅重量は密度 8960 kg/m³ から算出）。結果は線径・電流の
選び方によらず **消費電力 140〜22,000 W（電力予算 2.0 W の 70〜1万倍）、
コイル銅重量 460〜73,000 kg（衛星全備質量 1.25 kg の数百〜数万倍）** のレンジに
収まり、実現可能な組み合わせは存在しない。これは必要アンペア・ターン数
7.31×10⁵ A·turn 自体が 1U の体積・質量・電力予算に対して非現実的に大きいこと
に起因し、線径・電流のトレードオフでは解消できない。

**判定: 1U・2W・1.33kg という MOMO-SAT の制約下では、大気抵抗を相殺できる
磁気モーメントのコイルは質量・電力ともに 3〜4 桁以上不足しており、成立しない。**

## 3. 文献・既知技術との照合

### 3.1 磁気トルカがトルク専用アクチュエータとされる標準的理由

姿勢制御分野の標準的教科書（例: Wertz, *Spacecraft Attitude Determination and
Control*; Sidi, *Spacecraft Dynamics and Control*）およびミッション設計の実務では、
磁気トルカ（magnetorquer / magnetic torque rod）は一貫して「トルク発生装置」
として扱われ、軌道制御（推進）用途には位置づけられない。理由は本書 §1.1 で
導出した通り、**局所的にほぼ一様とみなせる地球磁場中では、電流ループに働く
正味の力はゼロに近く、有意に得られるのはトルクのみ**という一様場近似が
CubeSat〜大型衛星のスケールで極めて良い近似になるためである。B-dot 則による
デタンブル、RW 角運動量オフロード（脱飽和）は本質的にトルク制御であり、
MOMO-SAT の ADCS 設計（`docs/02_system_architecture.md` §2.4、
`fsw/adcs/controller.py`）も同じ位置づけで MTQ を用いている。この設計判断は
本検証の結果（F_max ≈ pN、τ_max ≈ μN·m）と整合している。

### 3.2 実際に磁場との相互作用で軌道変更が可能な技術との対比

過去文献の主張が「電磁気的な力そのものが軌道制御に使えない」という趣旨ではなく、
「**閉じた電流ループ（トルカ）という構成では使えない**」という趣旨であることは、
以下の対比技術が実証されていることからも裏付けられる。

#### (a) 電気力学テザー（EDT: Electrodynamic Tether）

EDT は長い（多くは数百 m〜数十 km）導電性テザーに電流を流し、地球磁場との
相互作用力 **F = I L × B** を推力（または制動力）として使う。MTQ との
決定的な違いは、**電流経路が閉じたループではなく、電離圏プラズマが帰路
（リターンパス）を構成する**点にある。これにより ∇(m·B) 型の（ほぼゼロの）
力ではなく、直接的なローレンツ力 I L×B が正味の力として働く。

代表的な実証ミッション（訓練知識ベース、軌道・電流条件は文献値のオーダー）:
- **TSS-1R**（1996, Tethered Satellite System, NASA/ASI）: 約 19.7 km 展開の
  導電テザーで最大約 1 A・数百 V を発生・電流駆動し、実測された抗力／推力は
  ニュートン級（〜0.1〜数 N オーダー）に達したと報告されている。
- **PMG**（Plasma Motor Generator, 1993）: 短尺テザーで電流駆動によりテザー系の
  運動エネルギーが変化することを実証（力のオーダーは短尺・低電流条件のため
  TSS-1R より小さいが、原理実証として重要）。
- **KITE**（Kounotori Integrated Tether Experiment, 2017, JAXA HTV6）: 約 700 m
  テザー展開を試みたが分離機構の不具合で電流駆動実験は未達。ただし EDT の
  デオービット用途としての設計自体は数百 m〜km 級テザーで mN〜数十 mN
  オーダーの制動力を想定していた。

いずれの例も、**MTQ（0.1m スケールの閉ループ、m ≤ 0.2 A·m²）とは電流経路の
トポロジーとスケール（テザー長 100m〜20km 対 MTQ の実効長 0.1m 程度）が
本質的に異なる**。EDT の力のオーダー（mN〜N 級）と本検証の MTQ 並進力上限
（pN 級）を直接比較すると、10⁹〜10¹²倍の差があり、これは「同じ地球磁場との
相互作用」でも構成（閉ループ vs 開放電流+プラズマ帰路）で結果が全く異なる
ことを如実に示す。

参考として、テザー長 1km・電流 0.5A・B=2.49×10⁻⁵T という控えめな数値でも
```
F_EDT ~ I L B = 0.5 × 1000 × 2.487e-5 = 1.244e-2 N
```
となり、これは MOMO-SAT MTQ の F_max（2.17×10⁻¹²N）の **約 57 億倍**である。
（ただし 1U・1.25kg の MOMO-SAT にテザーを追加することは別途の設計問題であり、
本書のスコープ外。）

#### (b) ローレンツ力推進（帯電衛星、Peck らの研究）

Peck (2005) らが提案した「Lorentz-Augmented Orbit（ローレンツ力増強軌道）」は、
衛星自体を能動的に帯電させ（電子ビーム放出や電荷制御装置で表面電位を kV
オーダーまで上昇）、地球磁場中を運動する荷電衛星に働くローレンツ力
**F = q v × B** を軌道変更に利用する構想である。強磁場・高高度・高電位条件では
有用な力が得られると試算される一方、低軌道・低電位では、必要な帯電量を維持する
高出力電荷制御装置が CubeSat 級電力予算を大幅に超えること、高電位化に伴う
放電・アーキングのリスクがあることから、得られる力は µN〜mN オーダーに留まり
実証ミッションはなく概念研究段階に留まる。これも MTQ（電流ループ）とは異なる
電磁気機構（正味電荷×速度×磁場）であり、MOMO-SAT のような 1.25kg・2W・
0.2A·m² の MTQ 単体とは別カテゴリの技術である。

### 3.3 過去文献の報告の妥当性判定

以上を踏まえ、「MTQ による高度維持制御（軌道進行方向への増速）は電磁気力の
弱さと生じるのがトルクであることから利用できない」という報告を検証すると:

- 「生じるのがトルクである」という記述は、**一様磁場近似の下では数学的に厳密に
  正しい**（§1.1）。CubeSat スケールでは地球磁場の非一様性が極めて小さいため、
  この近似は現実に極めてよく成り立つ。
- 実際には非一様性による並進力 F=∇(m·B) が存在するが、MOMO-SAT の場合
  F_max ≈ 2.17 pN であり、大気抵抗（63.5 nN）に対して **4.5 桁小さい**（§2.3）。
- 大気抵抗を相殺するために必要な磁気モーメントは MOMO-SAT の MTQ 能力の
  **約 29,000 倍**であり、そのコイルは電力・質量ともに 1U CubeSat の予算を
  3〜4 桁超過する（§2.4）。
- 電磁気力そのものが軌道制御に使えないわけではなく（EDT、ローレンツ力推進は
  実証・研究例あり）、**閉じたループ電流という MTQ の構成そのものが軌道制御に
  不向き**という点が、過去文献の主張の物理的な核心である。

したがって、**過去文献の報告は妥当であり、本検証はこれを支持する**。

## 4. 結論

### 4.1 判定

**支持（Support）**: 「地磁気と衛星内電力による MTQ を用いた高度維持制御は、
電磁気力の弱さにより利用できない」という過去文献の報告は、MOMO-SAT の実機
パラメータに基づく定量評価によって支持される。

ただし、報告中の理由づけ「生じるのが力のモーメント（トルク）であることから」
という表現は、正確には以下の二段構えで理解すべきであり、単純な「トルクだから
力はゼロ」という説明は不正確である。

### 4.2 「トルクだから使えない」論と「力は小さすぎる」論の関係（正確な整理）

1. **第一段階（一様磁場近似）**: 地球磁場は CubeSat スケール（〜0.1m）に対して
   極めて良い精度で一様場とみなせる（§1.2 で見た通り、10cm 移動での磁場変化率は
   相対 4×10⁻⁸ 程度）。一様磁場中の電流ループに働く正味の力は、電磁気学の
   基本法則から**厳密にゼロ**であり、生じるのはトルク τ=m×B のみである。
   これが「トルクしか生まれない」という主張の物理的根拠であり、**近似としては
   正しい**。

2. **第二段階（非一様性による並進力の実在と大きさ）**: しかし地球磁場は
   大局的には非一様（r⁻³ 則で減衰するダイポール場）であり、この非一様性に
   由来する並進力 F=∇(m·B) は理論上ゼロではなく実在する。MOMO-SAT の
   MTQ（m_max=0.2 A·m²）で理想的に得られる F_max は約 2.17 pN、これによる
   軌道長半径変化率の理想上限は年間 9.9 cm 程度である。これは大気抵抗による
   自然減衰（年間 約 2.9 km）の **約 1/29000（4.5 桁小さい）** に過ぎず、
   実用上は「力がゼロ」とみなした場合と結果的に区別がつかないほど小さい。

すなわち、**「トルクのみ」という主張は一様場近似としては正しく、その近似が
破れて生じる並進力を定量評価しても、実用上は無視できるほど小さい（＝力が
弱すぎる、という第二の理由付けが最終的な結論を補強する）** という、両者は
矛盾する説明ではなく、近似の階層が異なる相補的な説明である。

### 4.3 MOMO-SAT で仮に試みた場合の定量的結論

| 評価項目 | 数値 |
|---|---|
| F_max（MTQ 最大並進力、理想上限） | 2.17×10⁻¹² N（≈ 2.17 pN） |
| τ_max（参考：MTQ 最大トルク） | 4.97×10⁻⁶ N·m（≈ 5 μN·m、姿勢制御には十分） |
| da/dt 理想上限（MTQ 常時最適方向） | 3.14×10⁻⁹ m/s（年間 約 9.9 cm） |
| da/dt 大気抵抗（高度低下） | 9.17×10⁻⁵ m/s（年間 約 2894 m） |
| 大気抵抗／MTQ 理想上限の比 | 約 2.9×10⁴ 倍（約 4.5 桁） |
| 大気抵抗相殺に必要な m_req | 約 5851 A·m²（MTQ 上限の 約 29,000 倍） |
| m_req 実現コイルの消費電力（試算） | 数百〜数千 W（電力予算 2.0 W の 100〜1万倍） |
| m_req 実現コイルの質量（試算） | 数百〜数万 kg（衛星全備質量 1.25 kg の 数百〜数万倍） |

MOMO-SAT（1U, 1.25kg, MTQ 0.2A·m², 平均 2W）において MTQ による高度維持
（軌道進行方向への増速）を試みた場合、理論上ゼロではない並進力が存在するものの、
その大きさは大気抵抗による自然減衰を相殺するには全く不十分であり、必要な
磁気モーメントを実現するコイルは 1U の質量・電力予算を 3〜4 桁超過する。
したがって、**MOMO-SAT の設計・運用において MTQ を高度維持（軌道進行方向への
増速）に用いることは物理的・工学的に成立せず、過去文献の報告と結論は一致する**。
MTQ は本ミッションの設計方針通り（`docs/02_system_architecture.md` §2.4）、
B-dot デタンブルおよび RW 角運動量オフロードといった**トルク制御専用**として
用いるのが妥当である。
